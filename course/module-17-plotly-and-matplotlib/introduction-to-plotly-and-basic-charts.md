## Introduction

Static images (like those generated by Matplotlib) are great for PDF reports and books, but modern web applications require interactive visualizations. **Plotly** is a high-level graphing library that produces interactive, publication-quality charts. Users can zoom in, pan, hover over points to view tooltips, and click legends to toggle data traces on and off in their browsers.

---

## Key Concepts

### Matplotlib vs. Plotly
- **Matplotlib**: Static PNG/PDF plots. Fast, stable, excellent for printing.
- **Plotly**: Dynamic HTML plots. Written in Javascript, renders in browsers, excellent for dashboards.

### Plotly Express
`plotly.express` (typically imported as `px`) is the easy-to-use, high-level API for Plotly. It takes a Pandas DataFrame as input and creates a fully configured figure in a single function call.

### Basic Interactive Charts
- **Line Chart**: `px.line(df, x="x_col", y="y_col", title="title")`
- **Scatter Plot**: `px.scatter(df, x="x_col", y="y_col", title="title")`
- **Bar Chart**: `px.bar(df, x="x_col", y="y_col", title="title")`
- **Pie Chart**: `px.pie(df, names="name_col", values="value_col", title="title")`

## Examples

### Example 1: Your First Plotly Line Chart
```python
import plotly.express as px
import pandas as pd

sample_data = {
    "x": [1, 2, 3, 4, 5],
    "y": [10, 20, 30, 40, 50]
}
sample_df = pd.DataFrame(sample_data)

# Create an interactive line chart
fig = px.line(sample_df, x="x", y="y", title="Plotly Line Chart")

# Open in browser
fig.show()
```

### Example 2: Interactive Scatter Plot
```python
import plotly.express as px
import pandas as pd

scatter_df = pd.DataFrame({
    "hours": [1, 2, 3, 4, 5],
    "marks": [50, 60, 70, 80, 90]
})

fig = px.scatter(scatter_df, x="hours", y="marks", title="Study Hours vs Marks")
fig.show()
```

### Example 3: Plotly Bar Chart
```python
import plotly.express as px
import pandas as pd

bar_df = pd.DataFrame({
    "course": ["Python", "Java", "SQL"],
    "students": [120, 90, 70]
})

fig = px.bar(bar_df, x="course", y="students", title="Course Students")
fig.show()
```

### Example 4: Plotly Pie Chart
```python
import plotly.express as px
import pandas as pd

pie_df = pd.DataFrame({
    "language": ["Python", "Java", "AI", "SQL"],
    "usage": [45, 25, 20, 10]
})

fig = px.pie(pie_df, names="language", values="usage", title="Language Usage")
fig.show()
```

## Notes

- Slicing methods in Plotly Express expect a Pandas DataFrame as their first argument, and column name strings as their `x` and `y` parameters.
- Calling `.show()` on a Plotly figure will temporarily host the interactive chart locally and open your default web browser to display it.

---

## Summary

- Plotly generates interactive, web-browser-ready visualizations.
- Use `plotly.express` (`px`) for rapid, single-line chart creation.
- Set up line, scatter, bar, and pie charts by passing a DataFrame and matching column header strings.
