## Introduction

While Plotly Express is excellent for quick, single-line chart creation, complex data visualization pipelines sometimes require fine-grained control over layout, styling, and multi-chart layouts. In this chapter, we will learn about **Plotly Graph Objects** for adding custom data traces, building dashboard-style subplot layouts, and exporting interactive charts to standalone HTML files. We will conclude with a real-world case study comparing both Matplotlib and Plotly.

---

## Key Concepts

### Plotly Graph Objects (`go`)
Unlike `plotly.express`, which automatically interprets DataFrames, `plotly.graph_objects` (`go`) is a lower-level API that requires manual trace configuration. It is much more powerful for building highly customized visualizations.
- Create figure container: `fig = go.Figure()`
- Add line/scatter trace: `fig.add_trace(go.Scatter(x=..., y=..., mode='lines+markers', name='label'))`
- Add bar trace: `fig.add_trace(go.Bar(x=..., y=..., name='label'))`
- Update layouts: `fig.update_layout(title="title", xaxis_title="X")`

### Dashboard Subplots
Use `make_subplots(rows=r, cols=c)` from `plotly.subplots` to build a grid of charts, and direct individual traces to specific cells using the `row` and `col` arguments in `add_trace()`.

### Exporting Plotly Charts
Use `fig.write_html("dashboard.html")` to export interactive charts. This generates a standalone HTML document containing the JavaScript bundle, which can be viewed in any browser or embedded in email notifications.

## Examples

### Example 1: Multi-Trace Line Plot with Graph Objects
```python
import plotly.graph_objects as go

fig = go.Figure()

# Add Trace A
fig.add_trace(go.Scatter(
    x=[1, 2, 3, 4],
    y=[10, 15, 20, 25],
    mode='lines+markers',
    name='Product A'
))

# Add Trace B
fig.add_trace(go.Scatter(
    x=[1, 2, 3, 4],
    y=[5, 10, 15, 20],
    mode='lines',
    name='Product B'
))

fig.update_layout(
    title="Sales Comparison (Graph Objects)",
    xaxis_title="Time Period",
    yaxis_title="Units Sold"
)

fig.show()
```

### Example 2: Dashboard-Style Layout with Subplots
```python
from plotly.subplots import make_subplots
import plotly.graph_objects as go

# Setup 1 row, 2 columns subplot grid
fig = make_subplots(rows=1, cols=2)

# Add line chart to row 1, column 1
fig.add_trace(
    go.Scatter(x=[1, 2, 3], y=[10, 20, 30], name="Line Track"),
    row=1, col=1
)

# Add bar chart to row 1, column 2
fig.add_trace(
    go.Bar(x=["A", "B", "C"], y=[5, 7, 3], name="Category Count"),
    row=1, col=2
)

fig.update_layout(title_text="Multi-Plot Dashboard Layout")
fig.show()
```

### Example 3: Exporting Plotly Charts to HTML
```python
import plotly.express as px

fig = px.line(x=[1, 2, 3, 4], y=[10, 20, 30, 40], title="Export Example")

# Write to a standalone HTML file
fig.write_html("plotly_chart.html")
print("Plotly Chart Exported to HTML Successfully")
```

### Example 4: Real-World Visualization Case Study
This example demonstrates a complete script that converts data into a Pandas DataFrame, creates a static Matplotlib bar chart, and generates an interactive Plotly scatter plot.

```python
import pandas as pd
import plotly.express as px
import matplotlib.pyplot as plt

# 1. Prepare Employee Data
employee_data = {
    "employee": ["Amol", "Snehal", "Rahul", "Priya", "Amit"],
    "salary": [50000, 60000, 55000, 70000, 65000],
    "experience": [5, 7, 4, 9, 6]
}
employees = pd.DataFrame(employee_data)
print(employees)

# 2. Matplotlib Static Chart
plt.bar(employees["employee"], employees["salary"], color="darkblue")
plt.title("Employee Salaries (Static)")
plt.xlabel("Employee")
plt.ylabel("Salary ($)")
plt.savefig("employee_salaries.png")
plt.show()

# 3. Plotly Interactive Scatter Plot
fig = px.scatter(
    employees,
    x="experience",
    y="salary",
    text="employee",
    title="Experience vs Salary (Interactive)"
)
fig.write_html("experience_salary_plot.html")
fig.show()
```

---

## Notes

- Stanadalone HTML pages generated by `write_html()` contain the full `plotly.js` library embedded within them (about 3MB in size). If you want to optimize size for web hosting, you can set `include_plotlyjs='cdn'` to fetch the Javascript library over the web.
- Plotly subplots grid indexes start at 1 (not 0), similar to Matplotlib's `plt.subplot()`.

## Summary

- Import the lower-level API using `import plotly.graph_objects as go`.
- Manually construct figures and register layers using `fig.add_trace()`.
- Create grid subplots using `make_subplots(rows, cols)` and update visual elements with `fig.update_layout()`.
- Save interactive visual pages using `fig.write_html()`.
