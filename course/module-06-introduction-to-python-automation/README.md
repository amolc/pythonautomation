# Module 6: Introduction to Python Automation

**Automation using Python — Part 1**

This module introduces the idea of automation, shows where Python fits into real-world business workflows, and prepares the development environment needed for the rest of the course.

---

## Learning Outcomes

- Explain what automation is and where it adds value
- Identify common automation use cases in business operations
- Recognize key Python libraries used in automation tasks
- Set up Python, a virtual environment, and a code editor for automation work
- Prepare a clean workflow for writing and running automation scripts

## Module Capstone

Set up a starter automation workspace that includes:

1. A project folder for automation scripts
2. A Python virtual environment
3. A `requirements.txt` file with basic automation libraries
4. A simple script that prints a status message and confirms the environment is working
5. Notes describing one business process you want to automate later in the course
