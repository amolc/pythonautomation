# Module 15: Image Processing with Python

**Automation using Python — Part 1**

This module introduces image-processing tasks that support automation workflows, including resizing, cropping, filtering, and OCR-based text extraction from images.

---

## Learning Outcomes

- Automate common image manipulation tasks with Python
- Understand when image processing is useful in automation workflows
- Apply simple image transformations such as resize and crop
- Recognize how OCR supports data extraction from images and scanned documents
- Connect image-processing steps to broader automation pipelines

## Module Capstone

Build a simple image automation workflow that:

1. Loads one or more image files
2. Applies a transformation such as resize or crop
3. Saves the processed output to a new folder
4. Runs OCR or recognition on at least one image if relevant
5. Documents expected image quality and limitations
