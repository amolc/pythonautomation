# Module 2: Data Types and Variables

**Automation using Python — Part 1**

This module builds practical fluency with Python data types, variable behavior, and string operations used in real automation work.

---

## Learning Outcomes

By the end of this module, you will be able to:

- Choose the right data type for insurance business data
- Work with `list`, `tuple`, `dict`, and `set` confidently
- Capture and format user input cleanly
- Use string operations to clean policy and claim records
- Avoid common variable and namespace mistakes
