# Module 14: PDF Automation

**Automation using Python — Part 1**

This module introduces PDF automation with Python, including reading existing PDF files, extracting text data, generating new PDF outputs, and converting PDFs into other useful formats.

---

## Learning Outcomes

- Explain where PDF automation is useful in business and reporting workflows
- Extract text and data from PDF files using common Python libraries
- Generate or manipulate PDF documents programmatically
- Convert PDFs to other formats such as text or images
- Recognize common limitations of PDF extraction and layout handling

---

---

## Module Capstone

Create a PDF automation workflow that:

1. Reads a PDF file and extracts useful text or values
2. Generates a summary output or transformed document
3. Performs one simple manipulation such as merge, split, or re-export
4. Converts the PDF into another useful format when needed
5. Documents extraction assumptions and limitations clearly
