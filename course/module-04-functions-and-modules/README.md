# Module 4: Functions and Modules

**Automation using Python — Part 1**

This module shows how to organize Python code for reuse, testing, and maintainability using functions, arguments, return values, and modules.

---

## Learning Outcomes

- Define reusable functions for repeated workflows
- Use parameters, default values, and return values correctly
- Understand variable scope in function execution
- Split scripts into modules and import them cleanly

## Module Capstone

Build a small package named `insurance_tools` with:

- `premium.py` → premium and tax functions
- `claims.py` → claim risk categorization function
- `reporting.py` → output formatting function

Then import these modules in a main script and generate a daily operations summary.
