# Module 12: Parallel Execution in Python

**Automation using Python — Part 1**

This module introduces ways to improve automation performance by running tasks concurrently or in parallel. It covers threading, multiprocessing, automation design considerations, and practical optimization techniques.

---

## Learning Outcomes

- Explain the difference between sequential, threaded, and multiprocessing execution
- Identify tasks that benefit from threads versus separate processes
- Apply safe automation practices when using parallel execution
- Recognize performance bottlenecks and choose simple optimizations first
- Build faster automation workflows without sacrificing clarity or reliability

## Module Capstone

Create a small automation workflow that:

1. Splits a repetitive task into independent units of work
2. Uses threading or multiprocessing appropriately
3. Measures or compares execution time
4. Handles shared resources carefully
5. Documents why the chosen concurrency model fits the task
