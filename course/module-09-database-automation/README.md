# Module 9: Database Automation

**Automation using Python — Part 1**

This module introduces how Python scripts connect to databases, run queries, and automate repetitive data tasks. It focuses on safe, practical workflows that support reporting, data updates, and operational automation.

---

## Learning Outcomes

- Explain what database automation means in Python workflows
- Connect Python to a database using common libraries
- Run automated queries and process results programmatically
- Insert, update, and organize data safely through scripts
- Apply basic best practices such as parameterized queries and transaction handling

## Module Capstone

Build a small database automation script that:

1. Connects to a sample SQLite database
2. Creates or uses a simple table such as `customers` or `claims`
3. Runs a query and prints filtered results
4. Inserts or updates a few rows safely
5. Writes a summary of the database operation to a log or output file
