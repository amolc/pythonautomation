# Module 8: GUI Automation

**Automation using Python — Part 1**

This module introduces GUI automation: controlling desktop interfaces with Python when no API or direct file-based integration is available. It focuses on practical concepts, safety, and common desktop automation patterns.

---

## Learning Outcomes

- Explain what GUI automation is and when to use it
- Automate simple mouse and keyboard actions with Python
- Understand how desktop applications can be controlled through repeatable steps
- Recognize the limits and risks of GUI-driven automation
- Apply safety checks and delays to reduce automation failures

## Module Capstone

Create a simple desktop automation workflow that:

1. Opens a target application or prepares a browser window
2. Uses timed delays and clear step order
3. Types sample data into a form or text field
4. Saves or submits the result safely
5. Includes notes on fail-safe steps and risks if screen layout changes
