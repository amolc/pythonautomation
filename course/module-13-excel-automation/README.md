# Module 13: Excel Automation

**Automation using Python — Part 1**

This module introduces practical Excel automation using Python. It covers reading and writing workbooks, handling different Excel formats, extracting data from worksheets and ranges, and automating common reporting and analysis tasks.

---

## Learning Outcomes

- Explain where Excel automation fits into business workflows
- Read and write Excel files using Python libraries such as `pandas`
- Understand common Excel file formats and compatibility concerns
- Extract data from worksheets, ranges, and structured sheets
- Automate repetitive Excel-based reporting and transformation tasks

## Module Capstone

Build an Excel automation workflow that:

1. Reads one or more Excel files
2. Extracts data from a chosen worksheet or range
3. Cleans or summarizes the data
4. Writes the result to a new Excel output file
5. Documents the steps and assumptions used in the automation
