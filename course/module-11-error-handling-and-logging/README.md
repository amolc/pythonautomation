# Module 11: Error Handling and Logging

**Automation using Python — Part 1**

This module explains how to make automation scripts more reliable by handling errors properly and recording useful execution details. These skills are essential for debugging, monitoring, and maintaining unattended automation workflows.

---

## Learning Outcomes

- Understand how exceptions affect Python automation scripts
- Use `try`, `except`, `else`, and `finally` blocks effectively
- Anticipate and handle common automation failures safely
- Implement logging for debugging, auditing, and monitoring
- Create automation scripts that fail clearly and recover where appropriate

## Module Capstone

Build a small automation script that:

1. Reads an input file or dataset
2. Handles at least one likely failure using exception handling
3. Logs script start, success, and failure events
4. Writes a clear status message or output file
5. Makes it easy to understand what happened during execution
