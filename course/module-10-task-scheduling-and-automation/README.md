# Module 10: Task Scheduling and Automation

**Automation using Python — Part 1**

This module explains how automation scripts can be scheduled to run at specific times or intervals. It connects Python scripting with real operational workflows such as daily reports, periodic checks, and recurring maintenance tasks.

---

## Learning Outcomes

- Explain why task scheduling is important in automation workflows
- Identify common scheduling options such as cron, Windows Task Scheduler, and scheduler libraries
- Design recurring automation jobs with clear timing and dependencies
- Recognize monitoring, logging, and failure-handling needs for scheduled tasks
- Build simple repeatable workflows that run without manual triggering

## Module Capstone

Design and implement a recurring automation job that:

1. Runs a Python script on a schedule
2. Generates a simple report or log entry
3. Handles missing inputs or basic failures cleanly
4. Stores output in a predictable location
5. Documents when the task runs and how to verify success
